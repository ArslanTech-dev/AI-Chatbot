## 🧠 About The Project

```yaml
Project:      AI-Chatbot
Type:         Conversational AI (Terminal-based)
Engine:       Microsoft Azure OpenAI Service
Language:     Python 🐍
Purpose:      Learn + Build real AI-powered applications
```

## 🚀 Getting Started

### ✅ Prerequisites

- 🟢 [Python](https://www.python.org/) 3.9 or higher
- 🟢 An **Azure account** with an [Azure OpenAI resource](https://learn.microsoft.com/azure/ai-services/openai/overview) deployed
- 🟢 Your Azure OpenAI **endpoint** and **API key**

### 📦 Installation

```bash
# 1️⃣ Clone the repository
git clone https://github.com/ArslanTech-dev/AI-Chatbot.git

# 2️⃣ Navigate into the folder
cd AI-Chatbot

# 3️⃣ Install dependencies
pip install -r requirements.txt

# 4️⃣ Set up your environment file
cp .env.example .env
# then edit .env with your real Azure OpenAI endpoint + API key

# 5️⃣ Launch the AI
python chatbot.py
```

## ⚙️ Configuration

Set these values in your `.env` file (see `.env.example`):

| Variable | Description |
|---|---|
| `AZURE_OPENAI_ENDPOINT` | Your Azure OpenAI resource endpoint URL |
| `AZURE_OPENAI_API_KEY` | Your Azure OpenAI API key |
| `AZURE_OPENAI_DEPLOYMENT` | The name of your deployed model (e.g., `gpt-4o-mini`) |
| `AZURE_OPENAI_API_VERSION` | The Azure OpenAI API version to use |

> 🔒 **Never commit your real `.env` file** — it's already excluded via `.gitignore`.
